# 能源用量校核流程

## 当前目标

首阶段从本地 Excel 中读取以下工作表，只读处理，不修改原工作簿：

- `2026年会投能源用量基础信息表`
- `2025年会投能源用量基础信息`

业务工作流由 `src/energy_submit_assistant/flows/energy_check.py` 编排；工作表解析位于 `modules/workbook_reader.py`，系数计算和误差判定位于 `modules/validator.py`，本地 HTTP 服务、启动控制窗口及浏览器定位由根目录 `energy_summit_assistant.py` 负责。

## 输入字段与比较方式

按列名读取月份、三级单位、能源类型、自用实物量、总实物量、表内自用/总标准煤和表内自用/总二氧化碳。对自用量和总量分别复算，并与对应表内列比较。

相对误差默认阈值为 1%，在 `config.yaml` 的 `app.tolerance_relative` 中配置：

```text
abs(复算值 - 表内值) / abs(表内值) <= tolerance_relative
```

表内值为 0 时，仅复算值也为 0 才一致。原始工作簿中的空白数量和结果值视为 0；无法解析为数字的非空数据不会静默改为 0。

## 能源换算规则

系数由 `config.yaml` 集中管理，计算形式为“实物量 × 系数”：

| 能源类型 | 标准煤系数 | 二氧化碳系数 |
|---|---:|---:|
| 电力（千瓦时） | 1.229 / 10000 | 0.604 / 1000 |
| 汽油（升） | 0.73 × 1.4714 / 1000 | 0.86 × 3.043 / 1000 |
| 柴油（升） | 0.86 × 1.4571 / 1000 | 0.86 × 3.145 / 1000 |
| 天然气（立方米） | 13.3 / 10000 | 21.6219 / 10000 |
| 热力（吉焦） | 0.0341 | 0.11 |
| 生活热水（吉焦） | 0.0341 | 0.11 |

汇总排除项：自来水、中水、冷量不计入标准煤；热力、生活热水、自来水、中水、冷量不计入二氧化碳。排除项的复算值按 0 处理。

**热力计费限制：** 截图还列出面积收费、蒸汽吨数计量和生活热水立方米计量等算法，但当前工作簿没有对应的收费/计量方式字段，且热力记录的能源类型带有吉焦单位。因此首版按吉焦系数处理；如业务需要支持其他口径，需在输入数据中增加方式字段或配置明确的分类来源。

## HTML 工作台

- 通过控制窗口选择“打开能耗统计页面”或“退出当前程序”；启动时默认自动打开页面。
- Windows 下新建 Chrome 窗口，并尝试移至主显示器工作区后最大化，不复用已有浏览器标签。
- 年份页签切换两个工作表；月份按时间顺序分组。
- 明细按月份、三级单位、能源类型排序，三级单位沿用工作簿原始名称。
- 月份、三级单位、能源类型筛选器放在对应表头下拉菜单中。
- 工具栏的“显示标准煤为零的能源类型”默认关闭；自用和总标准煤复算值都为零的记录默认隐藏。
- 每个月明细末尾显示月度汇总，按当前可见条目求和。汇总分别展示复算合计和表内合计；筛选、搜索或零值显示选项变化时动态更新。
- 表格显示复算值/表内值及逐项校核状态，支持搜索；输入 Excel 只读。

## 本地数据和凭据

- `input/` 下的真实工作簿由 `.gitignore` 排除，不应提交。
- `AI.env` 保存本机本地模型设置并由 `.gitignore` 排除；当前 Excel 校核工作流不调用模型。
- 计算系数、相对误差阈值和默认展示顺序应作为可公开配置维护，不在源码中散落重复。

## 后续数据源

后续计划从飞书云文档多维表格读取本地记录。接入时应新增独立读取适配模块，将其转换为与 Excel reader 相同的结构化记录，再复用现有计算模块和工作流；凭据留在本地环境配置中。
