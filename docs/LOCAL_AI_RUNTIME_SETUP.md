# 本地 AI 配置说明

## 当前状态

仓库根目录的 `AI.env` 保存本机本地 AI 服务设置，不纳入 Git。当前第一阶段的 Excel 读取、计算和 HTML 展示流程不调用 AI，也不会读取、改写或记录 `AI.env` 中的值。

项目入口 `energy_summit_assistant.py` 和 README 只说明配置文件用途，不在日志、页面或示例中输出 API Key、服务地址或本机模型路径。

## 配置约定

- `AI.env` 留在本机，由本地 AI 服务或后续 AI 模块按需读取。
- `.gitignore` 已排除 `AI.env`、`*.env` 和其他常见私有环境文件。
- 不要将真实 API Key、令牌、账号、模型文件路径或个人机器目录复制到 README、`docs/` 或公开示例。
- 如未来校核流程要使用本地 AI，应在配置层增加明确的读取入口，并由独立模块负责连接；Excel 计算规则仍由确定性公式完成，不能以模型推测替代。

## 后续接入

如需引入本地模型，先约定模型服务的 API 地址、模型标识、超时和是否由本项目管理服务生命周期，再新增占位值示例文件和对应配置加载逻辑。接入后应清楚标明哪些结果来自确定性计算，哪些是模型辅助建议；模型输出不得自动覆盖原始工作簿数据。
